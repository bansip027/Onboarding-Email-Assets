# PMS Logo Ticker

Assets and build output for the scrolling PMS logo ticker GIF used in onboarding emails.

## Layout

logos    Normalized source logo files, one per PMS brand.
frames   Generated intermediate frames for the scroll animation.
output   The final rendered ticker.gif (and any resized email variants).

## Brands covered

apaleo, Cloudbeds, Clock PMS, hop, Maxxton, MEWS, Oracle, StayNTouch
